# code-editor-fe
> 编译原理课程设计项目客户端

简易代码编辑器：
- 代码编辑
- 编译过程分析（编译器运行的五个阶段）
- 简易终端

后端程序：

https://github.com/coolarec/aclang

## 技术栈
- vue 3.2
- monaco-editor
- vue-class-component
- vue-property-decorator
- vite
- typescript

## 环境需求
### node 解释器环境
- nodeJS >= 22
- pnpm >= 8

### 集成 IDE
- VS Code

## 快速开始
### 安装依赖
```bash
pnpm i
```

### 启动本地开发
```bash
pnpm dev
```
浏览器访问项目运行端口
```
http://localhost:5173
```
